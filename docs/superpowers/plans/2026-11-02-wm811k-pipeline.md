# WM-811K Semi-supervised vs Supervised Pipeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a lot-aware wafer-defect classification study comparing supervised, self-supervised-pretrain+fine-tune, and FixMatch-style learning across label budgets, wrapped in a tracked, containerized, CI-gated, drift-monitored FastAPI service.

**Architecture:** A `wm811k` Python package (data, preprocessing, splits, models, training arms, evaluation) driven by Hydra configs and logged to MLflow. Training runs on a Colab A100 through the same package; the best registered model is exported and served by a FastAPI app in Docker, with Evidently-based drift checks on incoming traffic.

**Tech Stack:** Python 3.11, Poetry, PyTorch, scikit-learn, XGBoost, MLflow, Hydra, DVC, Evidently, FastAPI, pytest, ruff, Docker, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-02-wm811k-design.md`

## Global Constraints

- Python `>=3.11,<3.12`, managed with Poetry (as in `mlops-assignment`).
- `LSWMD.pkl` (~2.1 GB) is never committed to git; it is tracked by DVC and ignored by `.gitignore`.
- Report macro-F1 and per-class recall; never accuracy alone.
- Label budgets: 1%, 5%, 10%, 25%, 100% of labeled training maps; multiple seeds per arm and budget.
- All three arms share the same backbone (ResNet-18-class) for a fair comparison.
- Splits are lot-aware: no `lotName` appears in more than one of train/val/test.
- No cloud deployment and no Streamlit UI; serving is FastAPI only.

## Review Focus

1. **Old pickle under current pandas:** `LSWMD.pkl` was written by an old pandas and may fail to unpickle or have the `trianTestLabel` typo column; loading must fail with a clear message or work. (Task 2)
2. **Degenerate wafer maps:** tiny maps (e.g. 1x1), all-background maps, non-2D arrays. Resizing must not crash or invent values. (Task 3)
3. **Rare classes at tiny budgets:** at 1% some classes (e.g. Near-full) would round to zero samples; each class keeps at least one labeled sample and larger budgets are supersets of smaller ones. (Task 4)
4. **API garbage in:** wrong dimensions, values outside {0,1,2}, empty payload, oversized payload return a 4xx, not a 500. (Task 11)
5. **Drift on too little data:** a tiny current window must not raise or report a false alarm. (Task 12)
